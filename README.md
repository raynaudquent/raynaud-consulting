# brame-store.com – site Brame Store / Raynaud Consulting

Site vitrine statique (HTML + CSS, sans dépendance) pour l'activité de coaching vente auprès des commerces spécialisés et des concessions.

## Fichiers
- `index.html` : page d'accueil
- `mentions-legales.html` : mentions légales (compléter les champs entre crochets)

## À compléter avant la mise en ligne
- Logo (remplacer le bloc « LOGO » dans l'en-tête)
- Photo dans la section « À propos »
- Adresse e-mail de contact
- Lien du profil LinkedIn
- Témoignages clients
- Informations légales (SIRET, adresse, TVA)

## Publication avec GitHub Pages
Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
Pour utiliser le domaine brame-store.com : renseigner le domaine dans Settings → Pages, puis pointer le DNS chez le registrar vers GitHub Pages.

## Formulaire de contact
Le formulaire ouvre la messagerie du visiteur (mailto). Pour recevoir les messages directement, brancher un service comme Formspree et remplacer l'attribut `action` du formulaire.
